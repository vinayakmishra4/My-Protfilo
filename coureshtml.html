Get it running in under a minute

You only need a code editor and a browser — nothing to install.

01

Clone the repository

Pull every module down to your computer.

git clone https://github.com/vinayakmishra4/HTML-FOR-BEGINEERS.git
02

Open a module folder

Pick a module and open its files in your editor.

cd HTML-FOR-BEGINEERS
03

Edit, save, refresh

Open the HTML file in your browser, change the code, and refresh to see it live.

open index.html
